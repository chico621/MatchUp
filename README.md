⚽ Matchup – Youth Football Scheduling App
Matchup is a SaaS iOS application built with Expo, designed to simplify youth football match scheduling. It allows teams to arrange preseason and friendly fixtures directly — no league integration or intermediaries required.

🧑‍💻 Tech Stack
Frontend:
React Native (via Expo)

Backend: 
Python Flask
MongoDB 

Styling:
Tailwind CSS
