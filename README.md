# ⚽ Matchup – Youth Football Scheduling App

**Matchup** is a SaaS iOS application built with **Expo**, designed to simplify the process of organizing youth football matches. The app allows teams to arrange **preseason** and **friendly fixtures** directly with each other — completely removing the need for league integration or intermediaries.

---

## 📱 Features

- 🗓️ Schedule matches with other teams directly in-app  
- 📍 View upcoming fixtures and match history  
- 📬 Notifications and status updates for confirmed, cancelled, or pending matches  
- 🔍 Discover local teams open to friendlies  
- 🧠 Simple, intuitive UI designed for youth coaches and managers  
- 🔐 Authentication and secure user access  

---

## 🧑‍💻 Tech Stack

**Frontend:**
- React Native (via Expo)
- TypeScript
- File-based routing with Expo Router

**Backend:**
- Python (Flask)
- MongoDB (for user data, teams, matches, etc.)

**Styling:**
- Tailwind CSS
